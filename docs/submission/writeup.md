## Field 7 — About the project

Copy-ready answer (under 2,000 characters):

```text
An agent profile cannot show whether it handles work or a budget reliably. AgentFICO gives marketplaces and agent owners an open, free 300–850 trust score built from observed behavior. Reppo is central: real Reppo Eval verdicts drive the 35% work-quality factor, and evaluation IDs link to the judgments. Phoenix's replay moves from 691 to 696 after a real follow-up verdict on revised sample work (baseline: cmwaknixh000208jshh2w0av1; follow-up: cmwd5ia5r000008l8wqzthd4r). Versioned deterministic math sets every number; SERV text cannot change it.

SERV Reasoning powers seven logged jobs: (1) design checkable probe plans; (2) draft Reppo evaluation rubrics; (3) group Reppo critiques into recurring weaknesses; (4) explain cited reason codes and scores; (5) review detector-backed fraud signals; (6) map supported assistant logs into validated events; (7) generate labelled sample work for Reppo to judge. All jobs use structured output and validation. Configured features include Multipath (1, 2, 4, 5), Kronos (2, 5), Shadow Agent (1, 3, 4, 5), and Prompt Guard for untrusted text. Off: content-filter bypass; Kronos on 3, 6, 7 to limit cost; Multipath on 6 because it needs one output; Shadow Agent on 2, 6, 7.

Provenance: the five agent histories are simulated. Reppo verdicts are real provider assessments of synthetic samples and one project analysis of public chain data. The separate Kite example is an unaffiliated public mainnet address: 649 from 50 distinct transfer logs with partial coverage, so provisional. The simulator back-test AUC of 0.821 is not real-world validation.

For OpenServ SERV Hackathon Edition 02, we built the scorer, durable Reppo queue, evidence adapters, dashboard, API, and CLI. The demo runs from fixtures without keys.
```
